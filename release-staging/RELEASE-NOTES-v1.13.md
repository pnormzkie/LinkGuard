# LinkGuard v1.13 (versionCode 14)

A clearer, safer in-app update experience — see real download progress, survive a dropped
connection, and read a cleaner "what's new" screen.

## What's new

**Live download progress**
- Updating now shows a real percentage and size (e.g. 47% · 11.5 / 24.4 MB) right inside the
  app, with a progress bar — no more guessing from the notification shade.

**Handles a dropped connection**
- If your Wi-Fi or data drops mid-update, the download pauses ("Waiting for connection…")
  and resumes automatically when you're back online — your progress isn't lost. If a
  download can't finish, you get a clear Retry.

**Refreshed update screen**
- The "Update available" screen is redesigned: app icon, version, and an easy-to-read,
  bulleted list of changes instead of a cramped block of text.

## Notes
- Detection, scoring, and verdicts are unchanged.
- The update is still verified against the app's signing key before it can install — this
  redesign adds progress display only; it does not change that safety check.
- Signed with the same release key as prior versions; existing installs update in place.
