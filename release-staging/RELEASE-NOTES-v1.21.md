# LinkGuard v1.21

This maintenance release corrects the LinkGuard app icon on Android launcher and search surfaces.

## What's fixed

- Replaced the legacy cyan-shield fallback with the approved LinkGuard shield, chain-link, and alert-scanner artwork.
- Kept adaptive and fallback launcher icon resources visually consistent across supported Android launchers.

Detection rules, scoring, providers, networking, UI behavior, database behavior, and API configuration are unchanged.
