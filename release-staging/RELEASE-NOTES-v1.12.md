# LinkGuard v1.12 (versionCode 13)

Clearer risk flags — see exactly which vendors flagged a link, and grouped flags now reach
your Scan History too.

## What's new

**See which vendors flagged it**
- The "Vendors flagged" group now lists the specific security engines that flagged a link
  (e.g. Google Safebrowsing, Phishtank, Bfore.Ai PreCrime) instead of a bare count — tap to
  expand. The header count now reflects the true number of detections.

**Grouped flags in Scan History**
- Scan Report opened from your history now shows the same grouped, collapsible flags as a
  fresh scan. (Records saved before this update stay in the simple flat list.)

## Notes
- Detection, scoring, and verdicts are unchanged.
- Includes a safe database upgrade that preserves all your existing scan history.
- Signed with the same release key as prior versions; existing installs update in place.
