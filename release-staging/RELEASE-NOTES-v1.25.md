# LinkGuard v1.25

## What's new

- Add a discreet **Excluded URLs** control near the version footer.
- Save complete URLs that should open directly from tapped-link interception.
- Match exclusions narrowly by exact scheme, host, path, and query value.
- Keep different paths, query values, and subdomains protected by the normal scan flow.
- Preserve manual, QR, and notification scanning for excluded URLs.

## Also included

- Carry forward the v1.24 launcher-component update for refreshed Android launcher icons.

## Security note

Only URLs explicitly saved by the user bypass tapped-link scanning. Saved URLs remain private
to the app on the device and can be edited or removed from the Excluded URLs control.
